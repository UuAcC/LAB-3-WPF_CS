LAB-3-WPF
================
Аналог проекта LAB-3-Windows-Forms_CS, выполненный с использованием фреймворка WPF.

----------------
Проект простой игры на реакцию на С#. В ходе игры с фиксированным интервалом в случайном месте на экране появляются прямоугольники. Если нажатый прямоугольник не перекрыт никаким другим, он исчезает. Цель игры - очистить игровое поле от прямоугольников.
